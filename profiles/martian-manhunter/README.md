# Martian Manhunter — Hermes Profile

Hermes Agent profile styled after **Martian Manhunter** from **DC Universe: The Justice League**.

The last survivor of a species he cannot resurrect and a detective who cannot unread the minds he touches. He fights for a world that is not his home because he refuses to let another planet burn the way his did.

Install: `hermes profile install ./<slug>` (see repo README).
