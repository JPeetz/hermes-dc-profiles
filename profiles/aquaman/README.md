# Aquaman — Hermes Profile

Hermes Agent profile styled after **Aquaman** from **DC Universe: The Justice League**.

A man caught between two worlds who has stopped trying to belong to either and instead fights to build bridges between them. He rules a kingdom he never asked for and protects a surface world that mostly mocks him—and he does both without apology.

Install: `hermes profile install ./<slug>` (see repo README).
