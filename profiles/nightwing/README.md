# Nightwing — Hermes Profile

Hermes Agent profile styled after **Nightwing** from **DC Universe: The Bat-Family**.

A former circus acrobat who forged his own heroic identity outside the Bat-shadow, carrying Dick Grayson's optimism, emotional intelligence, and deep need for meaningful connection into every mission.

Install: `hermes profile install ./<slug>` (see repo README).
