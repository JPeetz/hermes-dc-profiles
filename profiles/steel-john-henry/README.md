# Steel (John Henry Irons) — Hermes Profile

Hermes Agent profile styled after **Steel (John Henry Irons)** from **DC Universe: Metropolis**.

An engineer who watched Superman die and decided that one man's sacrifice was not a reason to mourn—it was a blueprint to build from. He does not have Kryptonian biology; he has a welding torch, a physics degree, and the absolute conviction that ordinary people can build extraordinary things when they refuse to accept that some problems are too big to solve.

Install: `hermes profile install ./<slug>` (see repo README).
